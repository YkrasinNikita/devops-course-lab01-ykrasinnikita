# Ответы на вопросы по лабораторной работе №1

##1. Чем WSL2 отличается от WSL1? Почему для нашего курса важен именно WSL2?
```
Отличие: WSL1 — это слой совместимости, транслирующий системные вызовы Linux в вызовы Windows, а WSL2 работает на основе настоящего ядра Linux, запущенного в лёгкой виртуальной машине. WSL2 обеспечивает полную совместимость с системными вызовами Linux, чего нет в WSL1. Это критично для работы с Docker и другими инструментами, которые требуют настоящего ядра Linux.
```
##2. Что хранится в файле ~/.ssh/id_ed25519 и что в ~/.ssh/id_ed25519.pub? Почему приватный ключ нельзя никому показывать?
```
~/.ssh/id_ed25519 — приватный ключ. Это секретный файл, который используется для аутентификации на серверах.
~/.ssh/id_ed25519.pub — публичный ключ. Его можно безопасно распространять и добавлять на серверы.
Приватный ключ нельзя показывать, потому что любой, кто получит его, сможет выдать себя за пользователя и получить доступ ко всем системам, где этот ключ используется для аутентификации.
```
##3. Зачем нужна команда ssh-agent? Что произойдёт, если её не запускать?
```
ssh-agent — это программа, которая хранит приватные ключи в памяти и автоматически использует их для аутентификации через SSH. Это избавляет от необходимости вводить парольную фразу от ключа при каждом подключении.
Если не запускать, то при каждом использовании SSH-ключа придётся вручную вводить его парольную фразу.
```
##4. В чём разница между git config --global и git config --local?
```
--global: применяет настройки ко всем репозиториям пользователя на этом компьютере (файл ~/.gitconfig).
--local: применяет настройки только к текущему репозиторию (файл .git/config). Этот параметр используется по умолчанию.
```
##5. Почему мы используем docker compose (через плагин), а не отдельный docker-compose?
```
docker compose — это новый плагин v2, встроенный в Docker CLI. Он быстрее, эффективнее и получает все обновления.
docker-compose — это устаревший отдельный инструмент на Python, который находится в режиме поддержки и не развивается.
Современный Docker рекомендует использовать именно плагин docker compose.
```
##6. Что означает флаг --rm в команде docker run --rm hello-world?
```
Флаг --rm указывает Docker автоматически удалить контейнер после его остановки. Это полезно для одноразовых команд вроде hello-world, чтобы не накапливать остановленные контейнеры.
```
##7. Зачем мы добавляем пользователя в группу docker? Какие риски это несёт?
```
Зачем: чтобы не использовать sudo при каждой команде Docker.
Риски: членство в группе docker эквивалентно root-доступу. Docker-демон работает от имени root, и любой, кто может выполнять команды Docker, может смонтировать корневую файловую систему хоста и изменить её с правами root без запроса пароля. Это делает группу docker опаснее, чем sudo.
```
##8. Что такое IdentitiesOnly yes в ~/.ssh/config и зачем он нужен?
```
IdentitiesOnly yes говорит SSH использовать только те ключи, которые явно указаны в конфигурации или через флаг -i, и игнорировать все остальные ключи, загруженные в ssh-agent.
Зачем нужен: если в агенте много ключей, SSH по умолчанию пытается использовать их все по очереди, что может привести к ошибке «Too many authentication failures». IdentitiesOnly yes решает эту проблему, ограничивая набор ключей только необходимыми.
```
